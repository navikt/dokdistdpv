# Dokdistdpv
Dokdistdpv distribuerer digital post (dokumenter) til virksomheter (DPV) gjennom Altinn.

Distribusjonsbestillingene blir hentet fra MQ-kø og distribuert til Altinn via et SOAP-endepunkt. 
Mer informasjon om hvordan appen fungerer finner du på [Confluence-siden for dokdistdpv](https://confluence.adeo.no/display/BOA/dokdistdpv).
