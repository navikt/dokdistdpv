# Dokdistdpv

Dokdistdpv distribuerer taushetsbelagt post til virksomheter (DPV) gjennom Altinn.

Distribusjonsbestillingene blir hentet fra MQ-kø og lastet opp til Altinn.

[Dokumentasjon (Nav-internt)](https://confluence.adeo.no/display/BOA/dokdistdpv)

## Komme i gang

Kjør tester og bygg appen

```
mvn clean verify
```

## Henvendelser

Lag en issue i repoet.
