# Dokdistdpv
Dokdistdpv distribuerer taushetsbelagt post til virksomheter (DPV) gjennom Altinn.

Distribusjonsbestillingene blir hentet fra MQ-kø og distribuert til Altinn via et Altinn3. 

Mer informasjon om hvordan appen fungerer finner du på [Confluence-siden for dokdistdpv](https://confluence.adeo.no/display/BOA/dokdistdpv).
